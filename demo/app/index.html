01 / THE IDEA

Autonomy you can audit.

THE PROBLEM

Coding agents are capable and opaque. Where did the tokens go? What did the agent touch? Who decided the work was done, and can the next session pick it up?

Æion answers each question with a boundary you can inspect, not with a promise from the model.

  1. 01Contain

    Agent tools run inside an OpenShell sandbox: no host mount, no Docker socket, no network, no inference key. Model calls leave only through the host's counting relay.

  2. 02Observe

    Every model call and tool step becomes an OpenTelemetry span in Langfuse: tokens, cost estimate, duration and outcome. Metadata only: no prompts, source or hidden reasoning.

  3. 03Decide deterministically

    A protected gate runs the product checks. Then two approving reviewers from different model families must bind the identical artifact. Missing, reject or error never means approval.

  4. 04Remember

    At the 250k-token handover, claude-mem saves a checkpoint and reads it back. Hindsight keeps each session's analysis for recall. Memory advises; it never grants authority.

02 / ARCHITECTURE

One feature request, four lanes.

Control · execution · acceptance · evidence
  1. 1

    Select. The owner picks a ready feature MD in the cockpit. The controller checks admission (the qualified protocol is unchanged) and reserves budget in the ledger.

  2. 2

    Prepare. The acceptance contract is generated and frozen from the MD. A negative control proves it fails on the untouched base.

  3. 3

    Build. Flue starts a Pi agent session. Pi's tool calls (bash, read, write, edit, grep, glob) execute inside OpenShell through Flue's sandbox adapter.

  4. 4

    Meter. Every model call goes through the host's counting relay to OpenCode Go or the API. The relay counts tokens and cost, rechecks the lease and budget before each forward, and stops after 300 s of silence.

  5. 5

    Gate. The candidate runs the protected product checks in a disposable Docker boundary: no network, read-only root, non-root.

  6. 6

    Review. Two reviewers from different model families, excluding the author, must approve the identical artifact through a typed verdict.

  7. 7

    Publish. The publisher, which has no inference role, opens the product PR, waits for exact-head CI and confirms the merge on main.

  8. 8

    Observe and remember. Spans reach Langfuse through OpenTelemetry. claude-mem keeps the working checkpoint; Hindsight retains the session analysis.

THE DECISION RULE

Correct first.
Then efficient.

A cheap failed attempt still counts. A fast answer without a working artifact is not a success. Human assistance changes the autonomy result.

Collect comparable real runs before choosing a model.
