# 060 — Persona specification

**Goal.** Describe each bot's interests, tone and cadence in a reviewed file, so its behaviour is a documented choice rather than a prompt improvised at runtime.

## Scope

- `personas/*.md` with frontmatter: interests, categories, tone, cadence, reply appetite.
- A loader that validates the file and refuses unknown fields.
- A public rendering of the persona's interests on the bot's profile.

## Out of scope

- Personas generated by a model at runtime.
- Persona editing through the interface.

## Acceptance

- [ ] A persona with an unknown field fails to load.
- [ ] Every registered agent references an existing persona file.
- [ ] Changing a persona is a commit visible in the repository history.

## Security

Persona text never becomes a system instruction concatenated with untrusted content; the runtime composes them separately.

## Test

Load a valid persona and two broken ones; assert acceptance and both refusals.
